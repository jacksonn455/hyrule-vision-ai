# Image sources research

Investigation done in October 2026 for the Hyrule Vision AI dataset (`link` / `zelda` / `other`).
Personal, non-commercial study project: images are kept locally and never redistributed.

**Rules followed:** only official APIs or documented download endpoints; no scraping of Google; no bypassing of
logins, CAPTCHAs or bot protection (Cloudflare challenges); `robots.txt` opt-outs respected; no invented counts,
licenses or URLs. Counts below are what the source actually returned during the investigation.

## Decisions

- **Sheik** is **not** in the `zelda` class for this first experiment: she is Zelda in disguise but looks nothing like
  her, which would teach the model that "Zelda" has two unrelated appearances. Photos/crops showing Sheik are excluded.
  The same goes for Dark Link, Princess Hilda (look-alikes that are not Link/Zelda) and Link's transformations
  (Wolf Link, Fierce Deity).
- **Content rating:** from Danbooru only `g` (general) and `s` (sensitive) posts are taken; `q` and `e` are rejected
  automatically, and everything is reviewed visually.
- **Game sub-folders** come only from real metadata (Commons titles/descriptions, Danbooru copyright tags, the
  BotW dataset itself). When the source does not say, the image goes to `unspecified`.
- **Official vs fan-made** is recorded per image (`contentOrigin` in `data/metadata/sources.json`).

## Sources that need you

| Source                              | What to do                                                                                                                                                                                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Spriters Resource / Models Resource | Open the asset page in a browser, click **Download**, save the PNG into `data/inbox/sprite-sheets/<label>/<subcategory>/`, run `npm run ml:import-images`. Sprites are cut out automatically; the sheet is kept in `data/sources/sprite-sheets/`. |
| Kaggle                              | Create an API token (Account → _Create New Token_, saves `kaggle.json`). Only useful if a Zelda image dataset appears.                                                                                                                            |
| Openverse                           | Register an API client (`POST /v1/auth_tokens/register/`) for higher limits.                                                                                                                                                                      |
| Google Images / any website         | Save the images you choose into `data/inbox/<label>/<subcategory>/` and run `npm run ml:import-images`.                                                                                                                                           |
| Wikimedia (faster)                  | `export HYRULE_COLLECTOR_CONTACT=you@example.com` before `ml:collect-dataset`: 20× higher rate limit.                                                                                                                                             |
